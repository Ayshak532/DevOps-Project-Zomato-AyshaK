## 🔄 Project Stages:

### **Stage 1 – Deployment to Docker Container**

- Source code hosted on GitHub
- CI/CD pipeline using Jenkins
- Code quality analysis using SonarQube
- Dependency vulnerability scanning using OWASP
- Filesystem scanning using Trivy
- Docker image creation
- Docker image pushed to DockerHub
- Application deployed as a Docker container

### **Stage 2 – Deployment to Kubernetes Cluster with Monitoring**

- Docker image deployed to Kubernetes
- Kubernetes cluster configuration
- Application deployment and service configuration
- GitOps deployment using ArgoCD
- Prometheus monitoring
- Grafana dashboards
- Kubernetes application monitoring
